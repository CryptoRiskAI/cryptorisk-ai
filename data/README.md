# Dataset

This directory contains all datasets used by CryptoRisk AI.

## Structure

- `raw/`
  Original synthetic datasets generated by the team. These files should never be modified manually.

- `processed/`
  Cleaned and validated datasets used by the risk engine and clustering modules.

- `sample/`
  Small example datasets for testing and demonstration purposes.

## Dataset Information

The dataset represents a synthetic inventory of cryptographic assets used for demonstrating post-quantum risk assessment.

The project does **not** contain:

- Real organizational assets
- Certificates
- Cryptographic keys
- Personal information
- Sensitive infrastructure data
